# LocalDream Operit Plugin 📱🎨
**手机本地AI生图插件 — Operit 平台版**

基于 [xororz/local-dream](https://github.com/xororz/local-dream) ❤️ 开发的 Operit 插件，
在手机本地运行 Stable Diffusion，无需联网，保护隐私！

## 原项目

- GitHub: [xororz/local-dream](https://github.com/xororz/local-dream)
- Google Play: [Local Dream](https://play.google.com/store/apps/details?id=io.github.xororz.localdream)
- 感谢 [xororz](https://github.com/xororz) 的开源贡献！🙏

## 功能

- 🖼️ 手机本地AI生图（SD1.5 / SDXL）
- ⚡ 骁龙NPU加速，也支持CPU/GPU推理
- 🎨 支持自定义正向/反向提示词
- 📱 纯本地运行，隐私安全

## 安装

### 方法一：AI 自动安装 🤖
直接把本仓库链接扔给你的AI助手，让它帮你下载安装~

### 方法二：手动安装 ✋
将 `com.operit.localdream_gen` 文件夹放入 Operit 的 `dev_package` 目录即可。

## 使用方法

在对话中调用生图工具即可自动生成。

### ⚠️ 重要：后台运行

LocalDream 加载模型后请确保 APP 保持后台运行（小窗模式 或 设置无限制后台，二选一即可），否则可能被系统清理导致生图失败。

首次生图较慢属正常现象（需编译Shader），后续会快很多~
